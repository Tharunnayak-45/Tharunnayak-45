## 🤖 AI Resume Screening & Job Recommendation System

> **An intelligent web application for resume analysis, ATS-style scoring, skill extraction, and job matching.**

The **AI Resume Screening & Job Recommendation System** is a full-stack application designed to analyze resumes and provide meaningful insights about a candidate's profile.

The application accepts **PDF and DOCX resumes**, extracts their content, identifies technical skills, evaluates resume quality using an **ATS-style scoring model**, and compares the resume against job requirements.

It also identifies **matched and missing keywords**, calculates job-description similarity using **TF-IDF and cosine similarity**, and provides job recommendations based on detected skills.

### ✨ Key Features

* 📄 **PDF & DOCX Resume Parsing**
* 🧠 **Automatic Skill Extraction**
* 📊 **ATS-Style Resume Score — 0 to 100**
* 🔍 **Keyword Matching & Analysis**
* 🎯 **Job Description Comparison**
* 📈 **TF-IDF & Cosine Similarity**
* 💼 **Skill-Based Job Recommendations**
* ⚡ **Resume Quality Analysis**
* 💡 **Resume Improvement Suggestions**
* 🔐 **Secure User Authentication**
* 🗄️ **MySQL Database Integration**
* 📱 **Responsive Modern UI**

### 📊 ATS Analysis

The system evaluates resumes across multiple categories:

| Analysis Category      | Maximum Score |
| ---------------------- | ------------: |
| 🧠 Skills              |            20 |
| 📑 Resume Sections     |            22 |
| 📞 Contact Information |             6 |
| 📄 Resume Length       |            10 |
| ⚡ Action Verbs         |            10 |
| 📈 Quantified Results  |             7 |
| 🎯 Job Keywords        |            25 |
| **Total**              |       **100** |

### 🧠 Technologies Used

**Python • Flask • MySQL • HTML5 • CSS3 • JavaScript • NLP • Machine Learning • TF-IDF • Cosine Similarity • Scikit-learn • PyPDF2 • python-docx**
